2 · Importing a very large sheet, a batch of rows at a time

A workbook with a quarter of a million rows is not a file problem, it is a record problem. Here the sheet is parsed in a Web Worker, then posted to the API in batches of 100, 500 or 1000 rows — the progress bar advances once per batch, each batch is validated server-side, and the rows that fail come back with the reason why. Roughly one row in 150 of the generated data is deliberately broken.
